# ⬡ Nexus AI — Local AI Powerhouse

**Nexus AI** is a professional-grade, custom-UI local AI application built with Streamlit and Ollama. It features smart model routing, multi-document RAG indexing, vision capabilities, a Python code execution sandbox, and automated PowerPoint presentation generation—all running 100% locally on your machine.

## 🚀 Core Features
* **Smart Model Routing:** Automatically switches models based on your input files (Vision for images, Llama for PDFs/Text, Qwen for coding).
* **Local Math Reasoning:** Integrated with DeepSeek-R1 for step-by-step logical problem solving.
* **PowerPoint Engine:** Type `ppt: <topic>` to autonomously generate and download formatted `.pptx` presentation slides.
* **Code Sandbox:** Safely execute Python code snippets generated by the AI directly inside the app interface.
* **Chat History Export:** One-click download of your entire session history as a Markdown file.

---

## 🛠️ Technology Stack
* **UI:** Streamlit (Custom Dark-Mode CSS Architecture)
* **Backend LLM Hosting:** Ollama
* **Scripting:** Python (`python-pptx`, `PyPDF2`, `PIL`, `psutil`)

## 📦 Prerequisites & Model Installation

Make sure you have [Ollama](https://ollama.com/) installed and running on your system. 

Open your terminal/command prompt and download the required local models by running these commands:

```bash
# Default coding and general assistant model
ollama pull qwen2.5-coder:7b-instruct-q4_K_M

# Vision model for image analysis
ollama pull llava:7b

# Text model for RAG document reading and PowerPoint generation
ollama pull llama3.1

# Lightweight reasoning model for math and logic puzzles
ollama pull deepseek-r1:1.5b

# ==========================================
# NEXUS AI — COMPLETE INSTALLATION SCRIPT
# ==========================================

# 1. Clone your repository (replace with your actual GitHub link)
git clone https://github.com/YOUR_USERNAME/nexus-ai.git
cd nexus-ai

# 2. Create and activate your Python virtual environment
python -m venv venv
venv\Scripts\activate

# 3. Install all required Python dependencies
pip install streamlit psutil requests ollama pillow pypdf2 python-pptx

# 4. Pull the required local AI models via Ollama
ollama pull qwen2.5-coder:7b-instruct-q4_K_M
ollama pull llava:7b
ollama pull llama3.1
ollama pull deepseek-r1:1.5b

# 5. Launch the application
streamlit run app.py
